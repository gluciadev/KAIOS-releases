# KAIOS

Instaladores de **KAIOS** para macOS (Apple Silicon) y Windows, y el canal del que la app descarga sus actualizaciones. El código está en otro repositorio.

## Instalar

Descarga la última versión en **[Releases](https://github.com/gluciadev/KAIOS-releases/releases/latest)**:

- **macOS**: `KAIOS-X.Y.Z-arm64.dmg`. Ábrelo y arrastra KAIOS a Aplicaciones.
- **Windows**: `KAIOS.Setup.X.Y.Z.exe`.

## Actualizaciones

KAIOS comprueba por su cuenta si hay versión nueva, la descarga en segundo plano y te avisa para reiniciar y actualizar. No hace falta volver a descargar nada.
